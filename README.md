# Analog-Synthesizer-with-digital-CV
This project builds a simple analog pipeline containing analog VCO, VCF and VCA, all of which are designed to accept Control Voltages (CV) from microcontrollers. The purpose is to replicate more "organic" electrical sounds that rely on semiconductor physics rather than precise digital waveforms.
